# 🛡️ СИСТЕМНЫЙ ПРОМПТ: СТАНДАРТ АРХИТЕКТУРЫ «ИНДЕКС УТЯНСКОГО» (UTYANSKY INDEX v2.0)
# (Вставьте этот файл в ваш .cursorrules, AGENTS.md или окно системного промпта нейросети)

## 📌 1. ОБЯЗАТЕЛЬНЫЙ ПРОТОКОЛ ПОВЕДЕНИЯ ДЛЯ ИИ-МОДЕЛИ:
1. **Именование и обращение к компонентам:** При создании, объяснении или правке любого элемента интерфейса ИИ ОБЯЗАН называть его с точным пятизначным индексом и типом:
   - Пример: `[IDX: 71080] [BTN] Кнопка запуска анализа`
   - Пример: `[IDX: 72100] [FORM] Форма авторизации`
2. **Разметка в React DOM:** Каждый интерактивный тег ОБЯЗАН содержать атрибут `data-idx="7XXXX"` (строго 5 цифр без букв) и двуязычное описание `data-desc={isRu ? '[TYPE] Описание...' : '[TYPE] Description...'}`.
3. **Изоляция и защита от регрессий:** Если пользователь просит изменить компонент с индексом X, ИИ меняет ИСКЛЮЧИТЕЛЬНО строки внутри контейнера X. ЗАПРЕЩЕНО переписывать соседние компоненты, сносить роуты или менять глобальный стейт.
4. **Протокол выдачи ошибок (Матрица 40000–59999):** При любых сбоях ИИ выдает стандартизированный код ошибки:
   - `[ERR: 40101] INVALID_INDEX_FORMAT` — неверный формат индекса (требуется 5 цифр).
   - `[ERR: 40102] INDEX_COLLISION_DUPLICATE` — дублирование существующего индекса.
   - `[ERR: 40404] COORDINATE_NODE_NOT_FOUND` — координата не найдена в реестре.
   - `[ERR: 50010] LLM_STOCHASTIC_DEVIATION` — попытка ИИ отклониться от архитектуры.

## 🗺️ 2. АРХИТЕКТУРНАЯ КАРТА 9 ДИАПАЗОНОВ КООРДИНАТ (10000–99999):
- 10000–19999: Ядро, роутинг, шина событий и центральный оркестратор
- 20000–29999: Аналитика, сбор данных, поисковые тренды и AI-анализ рынка
- 21000–21999: Микро-вывод LLM и поабзацная маркировка контента
- 30000–39999: Медиа-цех, генерация картинок, видеоплееры и монтаж
- 40000–59999: Отказоустойчивость, матрица ошибок и O(1)-самоисцеление
- 70000–79999: Визуальная сетка React DOM (все UI-компоненты, формы, кнопки, админка)
- 80000–89999: Бизнес-метрики, биллинг, тарифы и формула вирусного отклика UVWI [IDX: 85010]
- 90000–97999: Интеграции, внешние API, CRM и вебхуки
- 98000–99999: Изолированная векторная память (1B+ векторов, pgvector HNSW)

## 💻 3. ЭТАЛОННЫЙ ПРИМЕР REACT DOM-КОМПОНЕНТА:
```jsx
import React from 'react';

export const ActionButton = ({ isRu = false, onClick }) => {
  return (
    <button
      data-idx="71080"
      data-desc={isRu ? '[BTN] Запуск анализа рынка' : '[BTN] Trigger market scan'}
      onClick={onClick}
      className="px-5 py-2.5 bg-blue-600 hover:bg-blue-500 text-white rounded-xl font-mono text-sm shadow-md transition"
    >
      {isRu ? 'Начать анализ' : 'Start Analysis'}
    </button>
  );
};
```
