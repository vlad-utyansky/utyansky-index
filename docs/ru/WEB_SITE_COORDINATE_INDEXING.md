## 👁️ 1. Почему нейросети «слепнут» на современных сайтах?

Когда человек открывает сайт в браузере, он видит целостную картину: структуру, шрифты, цветовые акценты, кнопки целевого действия. Человеческий мозг мгновенно связывает визуальный образ с логикой взаимодействия.

Но когда с сайтом работает **искусственный интеллект** — будь то AI-редактор кода (**Cursor, Windsurf, Claude Code**), автономный веб-агент или поисковый бот нового поколения (**Яндекс Нейро, Perplexity, ChatGPT Search**), — он картинок не видит.

### Что видит ИИ в обычном HTML без Индекса:
```html
<div class="relative flex items-center justify-between p-4 bg-slate-800/80 rounded-2xl hover:bg-slate-700/80 transition-all cursor-pointer shadow-lg border border-slate-700/50">
  <span class="text-sm font-bold text-white tracking-wide">Заказать</span>
</div>
```

Для языковой модели это **бессмысленная каша из тысяч вложенных `<div>`**:
1. **Стили Tailwind ничего не говорят о роли элемента:** Классы `flex`, `p-4`, `bg-slate-800` описывают только отступы и цвет фона, но не объясняют, что это за сущность.
2. **Одинаковый текст кнопок:** На странице интернет-магазина или лендинга может быть 15 одинаковых кнопок «Купить», «Подробнее» или «Отправить». По какому признаку ИИ должен понять, какую именно кнопку вы просите перекрасить или снабдить новым событием?
3. **Галлюцинации и затирание кода:** Не понимая физических границ узла, нейросеть при первой же правке переписывает 800 строк окружающего компонента, сносит чужие обработчики событий (`onClick`, `useEffect`) или лениво оставляет коммент `// rest of code unchanged`, роняя весь экран в белый лист.

## 🧭 2. Решение: Координатная сетка Индекса Утянского (`70000–79999`)

Вместо стохастического угадывания «где-то там в середине файла», каждый функциональный узел сайта получает **несгораемый цифровой паспорт**:
1. **`data-idx="7XXXX"`** — уникальный пятизначный числовой адрес элемента в DOM.
2. **`data-desc="[ROLE] Описание"`** — строгое двуязычное смысловое определение функциональной роли узла.

### Тот же блок с Индексом Утянского:
```html
<div 
  data-idx="74010" 
  data-desc="[BUTTON] Главная кнопка прямого оформления заказа в CRM"
  class="relative flex items-center justify-between p-4 bg-slate-800 rounded-2xl">
  <span>Заказать</span>
</div>
```

### Что происходит внутри ИИ за 0.05 секунды:
* Нейросеть мгновенно отбрасывает весь визуальный мусор стилей;
* Строит детерминированное **дерево смыслов веб-страницы**:
  * `[IDX: 70000]` — Верхняя панель навигации (Header);
  * `[IDX: 71000]` — Главный первый экран (Hero Section) и базовое УТП;
  * `[IDX: 72000]` — Блок тарифной сетки и расчет стоимости;
  * `[IDX: 74010]` — Точка целевого действия (кнопка заказа).
* **Сложность поиска падает до $O(1)$:** ИИ правит ровно 40 строк изолированного контейнера `74010`. Соседние 2 000 строк файла физически защищены от случайных мутаций.

## 🛡️ 3. Двойная польза стандарта

### 1. Для разработчиков и вайбкодинга (Cursor, Claude Code, Windsurf)
* **0% затирания верстки:** вы формулируете задачу: `«В слоте 74010 замени текст кнопки на Оставить бриф»`. ИИ не перебирает проект часами — он выполняет точечную хирургическую правку за 3 секунды.
* **Экономия до 85% токенов:** в контекстное окно подается только целевой изолированный узел, а не портянка на 150 000 токенов.
* **Неубиваемые E2E-тесты:** селектор `page.locator('[data-idx="74010"]').click()` в Playwright / Cypress никогда не сломается при смене стилей, классов Tailwind или верстки.

### 2. Для поисковых роботов и AI-агентов (Яндекс Нейро, Perplexity, GPT Search)
* Поисковые нейросети 2026 года формируют прямые ответы вместо списка ссылок.
* Если сайт снабжен разметкой Индекса Утянского, робот парсит цены, контакты и оффер без искажений и галлюцинаций, повышая релевантность сайта в AI-выдаче.

## 📋 4. Правила разметки элементов веб-страницы

1. **Строго 5-значный числовой формат `data-idx`:** 
   Диапазон `70000–79999` зарезервирован под UI и веб-страницы. Никаких букв внутри индекса (например, `74010` — правильно, `btn-74010` — ошибка).
2. **Иерархия подуровней через дефис:**
   Для внутренних атомарных тегов контейнера используется числовой дефис:
   * `data-idx="74010"` — родительский контейнер формы;
   * `data-idx="74010-1"` — поле ввода телефона;
   * `data-idx="74010-2"` — кнопка подтверждения.
3. **Чистый двуязычный `data-desc`:**
   Атрибут обязан содержать тип элемента в квадратных скобках и понятное описание:
   ```jsx
   data-desc={isRu ? '[FORM] Форма экспресс-заявки' : '[FORM] Express inquiry form'}
   ```
4. **Индексируются смысловые узлы, а не каждый `<div>`:**
   Размечаются кнопки, ссылки, формы, карточки данных, модальные окна и крупные смысловые секции. Чисто декоративные обертки (`<div class="container mx-auto">`) размечать не требуется.

## 💻 5. Готовый пример: React-компонент с координатной разметкой

```jsx
import React from 'react';

/**
 * [IDX: 74100] Hero-блок лендинга с координатной защитой
 */
export const LandingHero = ({ isRu = true, onAction }) => {
  return (
    <section 
      data-idx="74100" 
      data-desc={isRu ? '[HERO] Главный экран с оффером' : '[HERO] Landing hero section'}
      className="py-20 text-center bg-slate-950 text-white"
    >
      <h1 
        data-idx="74101" 
        data-desc={isRu ? '[TITLE] Главный H1 заголовок' : '[TITLE] Main H1 heading'}
        className="text-5xl font-extrabold mb-6"
      >
        {isRu ? 'Сайт, понятный нейросетям на 100%' : '100% AI-Readable Website'}
      </h1>

      <div 
        data-idx="74110" 
        data-desc={isRu ? '[ACTIONS] Контейнер кнопок действия' : '[ACTIONS] Action buttons row'}
        className="flex justify-center gap-4"
      >
        <button
          data-idx="74111"
          data-desc={isRu ? '[BUTTON] Заказ коммерческого аудита' : '[BUTTON] Commercial audit button'}
          onClick={() => onAction && onAction('audit')}
          className="px-6 py-3 bg-blue-600 hover:bg-blue-500 rounded-xl font-bold transition"
        >
          {isRu ? 'Заказать аудит' : 'Request Audit'}
        </button>
      </div>
    </section>
  );
};
```

## 🔍 6. Интерактивный инспектор DOM (`utyansky-web-inspector.js`)

Чтобы включить подсветку координат («Взгляд ИИ») на любом сайте, достаточно подключить клиентский скрипт:

```html
<script src="src/utyansky-web-inspector.js"></script>
```

И вызвать в консоли или по клику на кнопку:
```javascript
UtyanskyInspector.toggle();
```

При активации инспектор:
* Очерчивает границы всех узлов `[data-idx]`;
* Отображает светящиеся бейджи с 5-значным индексом и описанием элемента;
* Выводит в нижнем углу HUD-панель с количеством узлов и гарантией $O(1)$-детерминизма.
