## 🛑 1. Проблема: Случайные утечки ноу-хау через ИИ

При масштабном вайбкодинге и использовании автономных ИИ-агентов (Cursor, Claude Code, Windsurf, Devin) возникает критический риск:
* **Неосознанный копипаст:** Агент при рефакторинге может скопировать приватные API-ключи, формулы ценообразования или коммерческие алгоритмы в публичный файл или README.
* **Слепота к секретам:** Стандартные правила `.gitignore` защищают только по расширению (например, `.env`), но бессильны, если чувствительная бизнес-логика написана на обычном JS или Python.

## 🔒 2. Двухуровневая Система Замков

Регламент v2.6.1 разделяет защиту на два независимых физических уровня:

| Индекс | Уровень | Назначение | Поведение всех ИИ-моделей |
| :--- | :--- | :--- | :--- |
| **`[IDX: 00000]`** | 🛑 **Уровень 1: Zero-Trust Lock** | **Запрет модификации:** защита стабильного кода от случайных правок. | ИИ не трогает блок без прямого указания слота. |
| **`[IDX: 00000-00000]`** | ⬛ **Уровень 2: Sensitive Information Vault** | **СТРОЖАЙШАЯ ТАЙНА И ANTI-LEAK:** защита ноу-хау и коммерческой тайны. | **АБСОЛЮТНЫЙ ЗАПРЕТ** на перемещение, экспорт на GitHub или цитирование в открытых сетях. |

## 🧱 3. Принцип Физической Изоляции (Air-Gap Vault)

Файлы чувствительной информации защищаются по правилу «Тройного Забора»:

1. **Физическая папка-сейф:**
   * Все секретные файлы хранятся строго в изолированной директории:
     `00_SENSITIVE_VAULT_00000_00000/`
2. **Физический префикс имени файла:**
   * Строгий числовой формат: `00000-00000-XXXXX_slug.ext`
3. **Заголовочная пломба в первой строке:**
   ```markdown
   <!-- [IDX: 00000-00000] РЕГЛАМЕНТ УТЯНСКОГО К ЧУВСТВИТЕЛЬНОЙ ИНФОРМАЦИИ -->
   <!-- СТРОЖАЙШЕ ЗАПРЕЩЕНО: Перемещение, публикация на GitHub, экспорт во внешние сети. -->
   ```

## 🛡️ 4. Аппаратные барьеры в Git и CI/CD

* **Фильтрация в `.gitignore`:** Маски `00000-00000-*` и `*VAULT*` аппаратно блокируют включение файлов в Git-коммиты.
* **Валидатор `guard_utyansky_slots.py`:** Блокирует любые попытки перемещения чувствительных файлов в открытые каталоги (`src/`, `examples/`, `docs/`, `sait/`).
